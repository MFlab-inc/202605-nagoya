# セットアップ手順書（やさしい版）

このプログラムを「あなたのPC」で動かして、Googleスプレッドシートに数字が並ぶまでの手順です。
専門用語はできるだけ避けて、**上から順番にやればOK**な形にしました。所要時間は初回でだいたい30〜40分です。

> 用語だけ先に2つ。
> - **サービスアカウント**＝「プログラム専用のGoogleアカウント（ロボット用のメールアドレス）」です。あなたの代わりにシートへ書き込みます。
> - **APIキー / 認証ファイル**＝「合鍵」です。これを使ってプログラムがデータ元やGoogleにアクセスします。**他人に渡さない**でください。

全体の流れ：

```
① 書き込み先のスプレッドシートを用意
② プログラム用のロボット(サービスアカウント)を作る
③ ロボットの合鍵(JSONファイル)をダウンロード
④ スプレッドシートをロボットに「共有」する
⑤ FRED(金利データ)の無料APIキーを取る
⑥ PCにプログラムと部品をインストール
⑦ 合鍵やIDをプログラムに教える（環境変数）
⑧ 実行して、シートに数字が並ぶのを確認
⑨ 毎日自動で動くようにする（任意）
```

---

## ① 書き込み先のスプレッドシートを用意する

1. ブラウザで https://sheets.google.com を開く
2. 「空白のスプレッドシート」を新規作成
3. 名前を分かりやすく（例：`FXデイトレ レート`）に変更
4. **URLの中の長い文字列＝「スプレッドシートID」**を控えておきます。

   URLはこんな形です👇 太字の部分がIDです。
   ```
   https://docs.google.com/spreadsheets/d/【1AbCdE...ここが長いID...XyZ】/edit#gid=0
   ```
   この `1AbCdE...XyZ` の部分をメモ帳などにコピーしておいてください（あとで使います）。

> タブ（シート名）は自分で作らなくて大丈夫です。プログラムが
> `fred_daily`（朝用）と `fx_evening`（夕方用）を自動で作ります。

---

## ② プログラム用のロボット（サービスアカウント）を作る

1. https://console.cloud.google.com を開く（初めてなら利用規約に同意）
2. 画面上の「プロジェクトを選択」→「**新しいプロジェクト**」→ 名前（例：`fx-rates`）→「作成」
3. 作ったプロジェクトが選ばれている状態にします
4. 上の検索窓に「**Google Sheets API**」と入力 → 出てきたものを開く →「**有効にする**」を押す
5. もう一度 検索窓に「**サービス アカウント**」と入力 → 開く
6. 「**サービス アカウントを作成**」→ 名前（例：`sheet-writer`）→「作成して続行」
7. 権限の選択は何も選ばず「続行」→「完了」でOK

これで「ロボットのメールアドレス」が1つできました。
例：`sheet-writer@fx-rates-123456.iam.gserviceaccount.com`
**このメールアドレスを控えておいてください**（④で使います）。

---

## ③ ロボットの合鍵（JSONファイル）をダウンロードする

1. 今作ったサービスアカウントの行をクリックして開く
2. 上のタブ「**キー**」→「**鍵を追加**」→「**新しい鍵を作成**」
3. 種類は「**JSON**」を選んで「作成」
4. すると `〇〇.json` というファイルが自動でPCにダウンロードされます

このJSONファイルが**合鍵**です。なくさないように、分かりやすい場所に置いてください。
例：`/Users/あなたの名前/fx-rates/service-account.json`

> ⚠️ このファイルは絶対に他人に渡したり、GitHubに上げたりしないでください。

---

## ④ スプレッドシートをロボットに「共有」する

ここが**いちばん忘れやすい大事な手順**です。

1. ①で作ったスプレッドシートを開く
2. 右上の「**共有**」ボタンを押す
3. ②で控えた**ロボットのメールアドレス**を貼り付ける
4. 権限を「**編集者**」にする
5. 「送信」（または「共有」）を押す

これで、ロボットがこのシートに書き込めるようになりました。

---

## ⑤ FRED（金利データ）の無料APIキーを取る ※朝用だけ必要

夕方用（FX）は不要です。朝用（金利）を使うときだけ取得してください。

1. https://fred.stlouisfed.org/ を開いて、無料の会員登録（Email登録）
2. ログイン後 https://fredaccount.stlouisfed.org/apikeys を開く
3. 「Request API Key」でキーを発行
4. 表示された英数字の文字列（APIキー）を控えておきます

## ⑥ PCにプログラムと部品をインストールする

1. PCに **Python**（3.9以上）が入っているか確認します。ターミナル（Mac）／コマンドプロンプト（Windows）で：
   ```bash
   python3 --version
   ```
   バージョンが出ればOK。無ければ https://www.python.org/downloads/ から入れてください。

2. このプロジェクトを置いたフォルダに移動して、必要な部品を入れます：
   ```bash
   cd フォルダの場所/fx_morning_rates
   pip install -r requirements.txt
   ```

---

## ⑦ 合鍵やIDをプログラムに教える（環境変数）

プログラムは「合鍵の場所」や「シートのID」を**環境変数**という形で受け取ります。
ターミナルで、その都度この3行（朝用は4行）を貼り付けます。

**Mac / Linux の場合：**
```bash
# 共通
export GOOGLE_SHEETS_ID="①で控えたスプレッドシートID"
export GOOGLE_APPLICATION_CREDENTIALS="③のJSONファイルの場所/service-account.json"

# 朝用(金利)を使うときだけ
export FRED_API_KEY="⑤で控えたAPIキー"
```

**Windows（コマンドプロンプト）の場合：**
```cmd
set GOOGLE_SHEETS_ID=①で控えたスプレッドシートID
set GOOGLE_APPLICATION_CREDENTIALS=③のJSONファイルの場所\service-account.json
set FRED_API_KEY=⑤で控えたAPIキー
```

> 毎回貼るのが面倒なら、後述の「⑨ 自動実行」でまとめて設定できます。

## ⑧ 実行して、シートに数字が並ぶのを確認する

まずは**通信なしのテスト**で、プログラム自体が壊れていないか確認：
```bash
python3 fx_fetcher.py        # → All fx_fetcher tests passed. と出ればOK
python3 fred_fetcher.py      # → All fred_fetcher tests passed. と出ればOK
```

次に**本番**。ネットにつないで実際にシートへ書き込みます：
```bash
python3 fx_fetcher.py --run     # 夕方用(FX)：fx_evening タブに書き込み
python3 fred_fetcher.py --run   # 朝用(金利)：fred_daily タブに書き込み
```

スプレッドシートを開いて、`fx_evening` / `fred_daily` というタブに数字が並んでいれば成功です🎉

## ⑨ 毎日自動で動くようにする（任意）

毎朝10:30・夕方16:10に自動実行したい場合の例です（Mac / Linux の `cron`）。

ターミナルで `crontab -e` を実行し、次を追記します（時刻は日本時間で書く前提。PCの時計が日本時間ならこのままでOK）：

```cron
# 環境変数（自分の値に置き換える）
GOOGLE_SHEETS_ID=あなたのスプレッドシートID
GOOGLE_APPLICATION_CREDENTIALS=/フルパス/service-account.json
FRED_API_KEY=あなたのFREDキー

# 朝 10:30 → 金利(前日確定データ)
30 10 * * 1-5 cd /フルパス/fx_morning_rates && /usr/bin/python3 fred_fetcher.py --run >> fred.log 2>&1

# 夕方 16:10 → FX・先物
10 16 * * 1-5 cd /フルパス/fx_morning_rates && /usr/bin/python3 fx_fetcher.py --run >> fx.log 2>&1
```

- `1-5` は「月〜金だけ」という意味です。
- `>> fred.log 2>&1` は、結果やエラーをログファイルに残す指定です。
- **PCがスリープ／電源オフだと動きません。** 常時動かしたい場合は、つけっぱなしのPCか、レンタルサーバー等での実行をおすすめします（必要なら別途ご案内します）。

## うまくいかないとき（よくある原因）

| 症状 | だいたいの原因と対処 |
|------|---------------------|
| `GOOGLE_SHEETS_ID is not set` | ⑦の環境変数を貼り忘れ。ターミナルを開き直したら再度貼る |
| `PermissionError` / 403 で書けない | ④の「共有」忘れ。ロボットのメールに**編集者**で共有したか確認 |
| `FRED_API_KEY is not set` | 朝用を動かすのに⑤のキーを設定していない |
| シートに `error` の行が出る | その銘柄だけ一時的に取得失敗。プログラムは止まらない設計なので、次回実行で更新されます |
| `ModuleNotFoundError` | ⑥の `pip install -r requirements.txt` をやり直す |
