# スプレッドシート内「更新ボタン」版（Google Apps Script）

PC・Python・合鍵JSON なしで、**シートを開ける人が誰でもボタン1つで更新**できる版です。
データ元は Yahoo Finance。`fx_evening` タブに、PC版と同じ日本語ヘッダーで書き込みます。

> ⚠️ 制限：建玉(open interest) はこのボタン版では空欄になります（chart API に含まれないため）。
> 価格・本日高安・出来高・状態(ok/preliminary/final/stale/error) は取得します。
> 建玉まで必要な日は、PC版（`fx_fetcher.py`）を使ってください。

## 取り付け方（初回だけ・約5分）

1. 対象のスプレッドシートを開く
2. 上のメニュー「**拡張機能**」→「**Apps Script**」をクリック
3. 開いたエディタの最初のコード（`function myFunction(){}` など）を**全部消す**
4. このフォルダの **`Code.gs`** の中身を**全部コピーして貼り付け**、保存（💾 または Ctrl+S）
5. エディタ上部の関数選択で **`updateRates`** を選び、「**実行**」を1回押す
   - 初回は「承認が必要」と出るので、自分のGoogleアカウントで**許可**（自分のシートを編集する許可です）
6. スプレッドシートに戻り、ページを**再読み込み**すると、上のメニューに
   「**FXレート**」が増えています

## 使い方

- メニュー「**FXレート → 今すぐ更新**」を押すだけ → `fx_evening` タブが最新になります
- シートを**共有された人**も、同じメニューから更新できます（各自、初回だけ許可が必要）

## 毎日自動でも更新したい場合（任意）

エディタで関数 **`createDailyTrigger`** を選んで一度「実行」すると、
毎日16時台（JST）に自動で更新されます（PCは不要・Googleのサーバーで動きます）。
止めたいときは、エディタ左の「**トリガー**（時計アイコン）」から削除します。

## PC版との関係

- **ボタン版（これ）**：誰でも・どこでも・準備なしで更新。建玉は空欄。
- **PC版（`fx_fetcher.py`）**：建玉も取得。自動実行や朝の金利(FRED)にも対応。

どちらも同じ `fx_evening` タブ・同じ列に書き込むので、併用しても上書きで揃います。
